- **fix(api):** `/v1/models` stale-while-revalidate rebuilds now run in Next's `after()` instead of `setTimeout(…, 0)`, restoring the flush-before-rebuild guarantee from #8728. The route had been passing `{ scheduleBackgroundRefresh: (task) => after(task) }` as a third argument to `getUnifiedModelsResponse`, which has taken two parameters since #9199 removed the injection point — so the object was silently discarded and `catalogCache` never imported `after` at all. Because `setTimeout(…, 0)` only yields one turn of the event loop, a catalog rebuild that blocks for hundreds of milliseconds delayed the stale response it was supposed to run behind ([#11581](https://github.com/diegosouzapw/OmniRoute/pull/11581))
