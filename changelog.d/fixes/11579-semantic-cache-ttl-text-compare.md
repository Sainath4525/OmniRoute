- **fix(cache):** semantic-cache entries no longer outlive their TTL by up to ~24h. `expires_at` is written as an ISO-8601 string but both read paths compared it against `datetime('now')`, which SQLite renders with a space where ISO has a `T`; the column is `TEXT`, so the lexicographic comparison put every row whose UTC calendar date was today ahead of "now" regardless of its time-of-day. A stale row was also re-promoted into the in-memory LRU on hit, so it survived eviction and restarts, and `getCacheStats()` counted it as live. Both sites now compare against a JS-built ISO cutoff, matching what `invalidateStale` already does ([#11579](https://github.com/diegosouzapw/OmniRoute/pull/11579)) — thanks @Meet6338-X for the report and root-cause analysis
